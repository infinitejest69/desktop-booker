# Security

DesktopBooker keeps guest details, so security problems matter.

## Reporting a problem
Please **don't** open a public issue. Instead use GitHub's private reporting: the **Security** tab of this repository → **Report a vulnerability**. Say what the problem is, how to reproduce it, and what it could expose. You'll get a reply as soon as possible.

## What's in scope
- Getting round the PIN sign-in or the staff / admin permissions.
- Reading or changing guest data without signing in.
- Leaking the email password (it's meant to live only in the system's password store).
- Anything that could corrupt bookings, bills or backups.

## Supported versions
Fixes go into the latest release only.
