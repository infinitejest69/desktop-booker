# AGENTS.md

Project guidance for coding agents. See also [CLAUDE.md](CLAUDE.md) for workflow and architecture rules.

## ui-sdk (`@ui-sdk/svelte`, `@ui-sdk/core`)

- Before using ui-sdk, follow the **ui-sdk skill** if it is installed, and read `node_modules/@ui-sdk/svelte/docs/llms.txt`.
- To build a new component, also search `node_modules/@ui-sdk/svelte/docs/core.md` by heading, and read `rendering.md` next to it (`node_modules/@ui-sdk/svelte/docs/rendering.md`).
