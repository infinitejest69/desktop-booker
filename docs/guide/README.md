## Signing in
Everyone has their own name and a 4 to 8 digit PIN. Choose your name, type your PIN and you're in. Press **Switch user** when someone else takes over the desk; the app also locks itself after a few idle minutes (15 unless an admin changes it). After five wrong PINs, signing in pauses for a short while.

There are two roles:
- **Staff** take and change bookings, check guests in and out, run bills, and look after rooms and guests.
- **Admins** can also set prices by hand, see reports and takings, set up the hotel, manage users and read the audit log. Under **My hotel** and **Reports** in the menu.

## Trying it out
On a new installation, the dashboard offers **Load demo hotel**: floors, rooms, suites, prices and some bookings to explore. Use a separate installation (or restore a backup afterwards) if you want to keep your real data clean.
